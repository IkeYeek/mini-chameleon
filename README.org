* The =mini-chameleon= educational-purpose project

=mini-chameleon= is an *educational-purpose* project aiming at designing a dense
linear algebra solver. At the beginning, the project comes only with testing
routines while the actual computational routines remain to be completed. The
goal is to implement a dense matrix-matrix product (GEMM) and an LU
factorization (GETRF).

The first step consists in a basic =sequential= implementation, possibly
considering blocking strategies. The second step is a =simd= enhancement. The
third step is a shared-memory (=openmp=) implementation. The fourth step is a
distributed memory (=mpi=) version. The fifth step is an hybrid =mpi+openmp=
version. There is also the possibility to implement a runtime-based (=starpu=)
version.

The project is named after the fully-featured [[https://gitlab.inria.fr/solverstack/chameleon][chameleon]] dense linear algebra
library.
